# TaskTracker

## Descrição

TaskTracker é uma aplicação de linha de comando para organizar tarefas pessoais. O planejamento lógico está sendo elaborado para a Fase 1 do Bootcamp II e servirá de base à implementação em Python da Fase 2.

## Escopo da entrega

O projeto será implementado em Python 3, com menu de terminal, cadastro de tarefas e listagem. O planejamento da Fase 1 será mantido em `docs/planejamento_logico.pdf`.

## Estrutura

```text
tasktracker-projeto/
├── README.md
├── .gitignore
├── docs/
│   └── planejamento_logico.pdf
└── src/
    └── main.py
```

## Execução

A implementação será concluída na Fase 2. Para executá-la depois, use `python src/main.py` no CMD dentro da pasta do projeto.
